# wb-trae-checkin

每天自动领取 **WorkBuddy** 和 **TRAE（国内版 / SOLO CN）** 的签到积分，装好就不用管。

> 非官方工具，仅供个人学习交流。接口来自社区逆向与实测，可能随官方调整失效。

## 每天能领多少

| 平台 | 规则 | 每月大约 |
|---|---|---|
| WorkBuddy | 第 1-6 天每天 100 分，第 7 天 1000 分（7 天一循环） | ≈ 6800 分 |
| TRAE（国内版） | 每天 200 Work 专属积分 | ≈ 6200 分 |

一个月漏签 10 天 = 白丢 2000+ 分。这个工具就是解决"忘了签"。

## 特性

- **全自动**：Windows 计划任务每天 4 个固定时段（00:05 / 09:00 / 12:30 / 19:00）+ **每小时兜底** + **每次开机登录后 30 秒**，静默执行，无窗口
- **常驻看门狗**：另有 `watcher.js` 在开机后驻留，每隔几分钟检查一次，**今天签完就自动退出**（平时 CPU 占用≈0）——就算所有定时触发都被系统吞掉，它也能补上
- **零依赖**：核心是一个 Node.js 脚本（>=18 即可），不用 `npm install`
- **不需要打开客户端**：直接调用官方签到接口，客户端开不开都行
- **幂等安全**：已签自动跳过，重复执行不会多领
- **真成功才算数**：领取后回查服务器状态确认到账
- **真实联网才执行**：Windows"网卡已连接"不可信（虚拟网卡/网页认证劫持都会误判），脚本用 Windows 同款 NCSI 内容校验 + API 真实应答探测，确认真断网就等（最长 20 分钟），等不到就交给下个时段
- **登录态竞态自动重试**：客户端会周期性重写凭证文件，脚本用递增退避重试（约 30 秒窗口）跨越写入期
- **限流自动换号重试**：TRAE 返回 9074 时自动更换设备号重试
- **桌面通知（延迟汇报 + 抗误报）**：新领到积分时立即弹 Windows 通知；若成功发生在你不在电脑前（如零点补跑），会在你登录后用电脑时补弹一次；登录态失效要**持续 30 分钟**才算真失效才提醒（单次失败是文件竞态，静默）；同一天不重复打扰。设环境变量 `CHECKIN_NOTIFY=0` 可彻底关闭通知
- **隐私安全**：只**读取**你本机的登录凭证，不修改、不上传任何文件，日志不打印 token

## 快速开始（3 步）

1. **装 Node.js**（已装可跳过）：<https://nodejs.org/> 下载 LTS 版，一路下一步
2. **登录两个客户端**：确保本机 WorkBuddy、TRAE 国内版至少登录过一次（登录过就行，之后不用开）
3. **双击 `install.bat`**：看到两个平台都显示 `OK` / `ALREADY` 就是装好了

安装器会自动完成：找到 Node → 生成静默启动器 → 注册两个计划任务（签到主任务 + 看门狗）→ 立即试跑一次并显示结果。

## 日常使用

- **什么都不用做**。积分每天自动到账
- 想看签到记录：打开本目录下的 `signin.log`
- 想手动补签：命令行执行 `node checkin.js auto`
- 想看当前状态（不领取，仅查询）：`node checkin.js status`
- 全天失败：你会收到 Windows 通知，按提示检查网络或重新登录客户端即可

## 常见问题

**Q：需要每天打开 WorkBuddy / TRAE 吗？**
不需要。脚本用的是登录时保存的凭证。只有约 60 天完全不开客户端导致凭证过期时，才需要打开客户端重新登录一次（会持续失败 30 分钟后收到通知提醒）。

**Q：电脑一直开着不关机，第二天还会签到吗？**
会。定时触发器按系统时钟正常打点；另有"每小时兜底"和常驻看门狗双保险。

**Q：开机时没联网 / 网卡连着但实际没网怎么办？**
三重保障：① 每次登录后 30 秒自动触发一次；② 每小时兜底触发器 + 常驻看门狗持续盯着；③ 脚本内用 NCSI 内容校验 + API 真实应答探测"真实互联网"，确认没网会等 20 分钟，等不到就静默交给下个时段，不会误报也不会浪费。

> 注意：安装时**故意不设置** Windows 的"仅网络可用时启动"，因为该判断在虚拟网卡/VPN/休眠唤醒后经常误判，而且被它拦下的任务不会被"错过补跑"机制救回（本项目就曾因它整天漏签）。

**Q：会占性能吗？**
几乎不占。签到主任务每次运行几秒到几十秒就退出。看门狗平时每 3 分钟只读一个小 JSON 文件（用阻塞式 sleep，CPU≈0%），**当天签完立即退出**，不会长期驻留。

**Q：TRAE 国际版能用吗？**
国际版额度自动发放、无需签到。本工具针对国内版（Trae CN / TRAE SOLO CN，积分互通）。

**Q：支持多账号吗？**
TRAE 会自动扫描本机多个客户端目录（SOLO CN / Trae CN）并去重；WorkBuddy 取当前登录账号。

**Q：怎么卸载？**
双击 `uninstall.bat`（会同时移除签到任务与看门狗任务）。日志等数据文件会保留在本目录，手动删除即可。

## 工作原理（简述）

1. 读取本机登录凭证（WorkBuddy：明文 JSON；TRAE：AES 加密的 storage.json，脚本本地解密，全程不出本机）
2. 调用官方签到接口（WorkBuddy：`/v2/billing/meter/daily-checkin`；TRAE：`/trae/api/v2/ug/checkin_credits/claim`）
3. 回查状态接口确认"已签到"后写入 `signin.log`

## 调度层次（三层保险）

| 层 | 组件 | 作用 |
|---|---|---|
| 1 | `DailyCreditCheckin` 计划任务 | 4 个固定时段 + 每小时兜底 + 登录触发 |
| 2 | `DailyCreditWatcher` 计划任务 | 开机驻留看门狗，持续盯到期完成 |
| 3 | `checkin.js` 内部 | 真实联网探测、请求重试、回查确认、竞态退避 |

## 安全说明

- 仓库不含任何密钥；所有凭证都在**你自己的电脑**上读取和使用
- **不要**把你的 `signin.log`、`trae_device_id.json`、登录态文件提交到公开仓库（`.gitignore` 已默认排除）
- 本项目与腾讯、字节跳动无任何隶属关系；使用风险自负，请遵守各平台服务条款

## 文件说明

| 文件 | 作用 |

| `last_result.json` | 最近一次执行的机器可读结果（供排查/二次开发） |
